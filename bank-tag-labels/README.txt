Bank Tag Labels - RuneLite Plugin
=================================
Zeigt auf jedem Bank-Tag-Tab (linke Leiste) einen Text an.

Benutzung im Spiel:
- Rechtsklick auf ein Tab -> "Set label" -> Text eingeben, Enter.
- "Clear label" entfernt den Text wieder.
- Ohne eigenes Label zeigt das Tab den Namen des Tags (abschaltbar in den Plugin-Einstellungen).

Starten (braucht JDK 11 oder neuer):
  Windows:   gradlew.bat run
  Mac/Linux: ./gradlew run
Es startet ein RuneLite-Client im Entwicklermodus mit dem Plugin.
